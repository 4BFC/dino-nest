Docnest는 **MIT License**로 공유되는 개인 문서 사이트 스타터입니다.

<h2 id="use-and-extend">자유롭게 사용하고 확장하기</h2>

개인용과 상업용으로 사용하고, 수정하거나 재배포할 수 있습니다.
복제본 또는 소프트웨어의 상당 부분을 배포할 때는 저작권 고지와 MIT 허가문을 함께 유지해 주세요.
전체 조건과 보증 제한은 [원본 LICENSE](https://github.com/4BFC/docnest/blob/main/LICENSE)에 있습니다.

<h2 id="project-origins">개발 출처</h2>

- 개발자와 저작권자: [4BFC](https://github.com/4BFC)
- 원본 프로젝트: [Docnest](https://github.com/4BFC/docnest)
- 저작권 고지: **Copyright (c) 2026 4BFC**
- 개발 배경: 개인 문서 사이트에서 정리한 Docusaurus와 React의 구성 방식을 재사용 가능한 스타터로 분리했습니다.

기본으로 제공하는 출처 링크는 템플릿의 개발 배경을 소개합니다.
MIT는 사이트 화면에 배지나 링크를 계속 표시할 것을 추가 조건으로 요구하지 않습니다.
화면 구성은 자유롭게 변경하되, 배포하는 코드의 저작권과 라이선스 고지는 유지해 주세요.

<h2 id="open-source-dependencies">함께 사용하는 오픈 소스</h2>

Docusaurus와 React 등 의존성에는 각 프로젝트의 라이선스가 적용됩니다.
헤더 글꼴인 [Pretendard](https://github.com/orioncactus/pretendard)는 SIL Open Font License 1.1로 제공되며,
글꼴과 라이선스는 `@dino-ovum/theme` 패키지에 함께 포함되어 있습니다.
직접 작성하거나 추가하는 문서와 이미지의 권리는 해당 저작권자가 정합니다.

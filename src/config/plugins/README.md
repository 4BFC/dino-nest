# plugins

Custom Docusaurus build extensions, imported as functions by `site.js`.

- `navigation.js`: public document navigation and lists, with localized category metadata.
- `recent-updates.js`: document dates and update-list data.
- `generated-module-compat.js`: ESM compatibility for generated files and server-rendering chunks.

Shared calculation functions are passed as plugin options. See [CONTRIBUTING](../../../CONTRIBUTING.md) for usage and compatibility details.
